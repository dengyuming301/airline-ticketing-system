# 航空客运订票系统（数据结构课程设计）

纯 C99 实现。**图形版启动即进入窗口界面，不出现黑色控制台。**

## 一、两个可执行文件

| 文件 | 说明 |
|---|---|
| `airline_gui.exe` | **双击运行**，打开 EasyX 图形界面 |
| `airline_console.exe` | 控制台版，命令行演示 / 答辩备用 |

所有输入框都支持**回车 = 确定、Esc = 取消**。

图形版操作全部在窗口内完成：左侧航班列表、右侧飞机座位图、底部按钮；姓名、身份证等文字输入使用自建输入对话框，支持中文，回车即可确定。

界面采用浅色主题；航班列表和座位图标题会显示**航空公司色牌**，按航班号前缀自动识别：南航（蓝）、国航（红）、东航（深红）、川航（橙）、深航（青）、海航（紫红），新增的其它航班显示为灰色“航空公司”。

## 三、图形版使用说明

启动后是主菜单，六个功能按钮：

1. **查询航线**：进入城市选择页。左侧选起飞城市、右侧选到达城市，城市按钮可直接点击（选中的变金色），也可点“手动输入”自己输入城市名；“不限”表示该方向不做限制。点“查询”后只显示符合条件的航班。
2. **订票**：先选择航班日期（可点击近期可飞日期，也可手动输入），再进入该日期专属的座位图；点击空闲座位（黄=已选）后点“订票”，填写姓名和身份证。也可以不选座，由系统自动分配。余票不足时可修改张数重试、登记候补，或查看同日同目的地且该舱位余票足够的推荐航班。
   - **三个舱位的座位都可以直接点**：点到商务舱或头等舱的座位时，会自动切换到该舱并高亮（之前选中的座位会清空，一次订票只属于一个舱位）。
   - 选中舱位后，座位图顶部会显示金色徽章“当前舱位：经济舱/商务舱/头等舱”；对应舱位的标题条变金色并加金色边框；其它舱位保持正常的空闲/已订颜色，不会被误认为“超出定额”。
3. **退票**：先选择航班日期（可点击近期可飞日期，也可手动输入），再填写姓名和身份证；系统按航班日期精确匹配订单。退票后按登记顺序寻找同日期、同舱位且张数不超过本次释放票数的候补，逐个询问；同一笔退票释放的票数会随成功补位递减，张数不足的候补保留在队列中并继续询问后续符合者。
4. **座位图**：选择航班查看三舱位实时座位状态（绿=空闲，红=已订，黄=已选）。
   - 座位图按机型生成：窄体机 B738 / A320 / A321 为头等 2-2、商务/经济 3-3；宽体机 A330 为 1-2-1 / 2-2-2 / 2-4-2，B787 为 1-2-1 / 2-2-2 / 3-3-3。
   - 标题会标注“宽体机 / 窄体机”，每个舱位条显示分组（如“经济舱 2-4-2”），过道在座位图中以更宽的间隙呈现。
5. **模拟登机**：选择航班后点“模拟登机”，显示升舱 / 强制退票日志。
- 航班列表每页 15 条：超过时底部出现“上翻 / 下翻”，也支持鼠标滚轮和 ↑↓ / PageUp / PageDown。
- 管理员选择航班时同样分页，每页 15 条，底部有“上一页 / 下一页”。

6. **管理员**：新建航线、修改乘员定额、修改票价、修改飞行日 / 飞机号、查看全部订票记录、超售演示。
   - 所有表单都支持**点击选择 + 手动输入**：航班、起飞/到达城市、飞机号、舱位、飞行日都可以直接点选项（金色为当前选中）；每个可选项旁边都有“手动输入”，列表里没有的也能自己填。
   - 新建航线的飞行日可多选（周一~周日、每天）；定额、票价、航班号点按钮直接输入。
   - 城市选项最多显示 9 个；手动输入的城市会以金色按钮显示在页面上，创建航线后自动加入城市选项。
   - 新建航线提供航空公司选项（南航 CZ、国航 CA、东航 MU、川航 3U、深航 ZH、海航 HU、厦航 MF）；选中后航班号会自动带上对应代码前缀，例如选南方航空后输入 3101 会得到 CZ3101。
   - 修改机型时会同时切换座位布局；如果该航班已有订票记录，会拒绝更换机型（座位号会错乱），需先办理退票。

窗口右上角关闭按钮可直接退出；任何列表 / 详情页按 Esc 返回上一级。

## 四、与题目要求的对应关系

### 基本要求

| 题目要求 | 实现 |
|---|---|
| 航线信息：起点、终点、航班号、飞机号、飞行日、定额、余票、价格（分舱位）、已订票名单、候补名单 | `Flight` / `Booking` / `Waiter` 结构体 |
| 程序启动时至少 15 条航线 | `airline.c` 的 `kInit[]` 硬编码 15 条 |
| 查询航线（按起点或终点） | 主菜单“查询航线”；列表显示航班号、机型、飞行日、余票 |
| 订票：有余票出座位号，否则询问候补 | 座位图点选或自动分配；失败时提示并推荐同目的地航班，可登记候补 |
| 退票：退票后依次询问候补客户 | 退票后按候补队列顺序自动补位并显示补位名单 |
| 管理员新建航线 | 管理员 → 新建航线 |
| 管理员修改航线（合法性校验） | 修改定额时不能小于已售数量，缩容不能挤掉已占座位 |
| 查看并打印所有订票记录 | 管理员 → 查看全部订票记录（可上下翻页） |

### 扩展要求

| 题目要求 | 实现 |
|---|---|
| 订票失败推荐同目的地其它航线 | 订票失败弹窗后，列表中可继续选择其它航班；核心函数 `recommend_flights()` 控制台版会直接打印推荐 |
| 允许超卖，阈值自定 | 每舱位超售阈值 = 定额的 10%（至少 1 张），字段 `overbook` |
| 模拟登机：经济→商务→头等升舱，仍超员则强制退票 | 管理员 / 主菜单“模拟登机”按钮 |
| 强制退票原则：最后订票先退 | 按全局订票序号 `seq` 取最大者 |
| 打印调整名单、强退名单 | 模拟登机结果以文本页显示，可翻页 |
| 图形化显示飞机与订票情况 | 主界面右侧座位图；三舱位分区、实时颜色、余票与占用率统计 |
| 订票时可选座位 | 订票流程中直接点击座位图选择，黄底为已选；也可不选 |

## 五、编译

### 图形版（需要 EasyX + MSVCRT 版 MinGW）

```bat
build_easyx.bat
```

- EasyX 的 MinGW 库是 **MSVCRT** 版本；若 gcc 是 UCRT 版本，链接会报 `__imp___iob_func`。
- `gui.c` 和 `easyx_view.c` 按 C++ 编译（EasyX 依赖 C++），`airline.c` 按 C99 编译。
- 使用 `-mwindows`，所以运行时不带控制台窗口。

### 控制台版（任何 C99 编译器）

```bat
build_console.bat
```

等价命令：

```bat
gcc -std=c99 -Wall -Wextra -O2 -o airline_console.exe src\airline.c src\main.c src\easyx_view.c
```

Dev-C++：新建 Console Application，把 `src` 下 `airline.c`、`main.c`、`easyx_view.c` 和 `airline.h` 加入工程。

## 六、数据结构说明

| 结构 | 用途 | 复杂度 |
|---|---|---|
| `Flight g_flights[200]` | 航线顺序表 | 查找 O(n) |
| `Booking` 单链表 | 每航班订票记录，按订票顺序追加 | 插入 O(1) |
| `Waiter` 单链表 | 候补队列，先进先出 | 入队/出队 O(1) |
| `taken[3][20][9]` | 三舱位座位占用位图（最多 9 列） | O(1) |
| `cols` / `grp` | 各舱位每排座位数、过道分组（按机型） | O(1) |
| `weekMask` | 7 位位图表示周一至周日 | O(1) |

超售阈值：`overbook = cap / 10`，最小 1 张。

## 七、关键算法

1. **最近航班日期**：从今天起最多推 7 天，逐日检查 `weekMask` 对应位；`mktime` 处理跨月跨年。
2. **座位分配**：行优先扫描空闲座位；超出定额的票记 `SEAT_NONE`，表示超售无座。
3. **候补补位**：退票释放额度后按队列顺序逐个尝试订票，成功即出队。
4. **升舱**：经济舱 → 商务舱 → 头等舱；优先无座旅客，其次最后订票者。
5. **强制退票**：同舱位订票序号最大者整单退掉，直到人数不超过定额。

## 八、已知取舍

- 每笔订单和候补记录均保存具体航班日期；日期须符合该航线的每周飞行日。
- 一次预订最多 8 张（`MAX_SEATS`）。
- 强制退票按整张订单退，不拆单；可能退完后略少于定额。
- 数据保存在内存中，退出程序即清空。

## 九、编码说明

源码统一 UTF-8。控制台版在 `main()` 中调用 `SetConsoleOutputCP(CP_UTF8)`；图形版所有中文通过 `MultiByteToWideChar` / `WideCharToMultiByte` 转换后显示。
